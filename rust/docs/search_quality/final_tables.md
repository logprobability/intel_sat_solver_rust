# The final comparison of the search extensions

Generated by `scripts/search_quality_final.py` with the release build: 100 instances (78 regression instances, 22 generated formulas), 9 configurations, timeout 60 s, 4 jobs; the CPU time is the minimum of 3 runs. Every model was verified by the tool (`/topor_tool/verify_model 1`).

**SAT versus UNSAT contradictions between the configurations: none.**

The configurations:

* `base`: the defaults: the search of the C++ solver
* `hints`: phase and score hints carried over from the baseline run of the same instance (`/phase/hints/on 1 /decision/score_hints/mult 10 /topor_tool/hints_file <file>`): advice from a previous run of the very same instance, so an upper bound of what carrying state over can give, not a setting one can just switch on
* `target`: `/phase/target/on 1 /phase/rephase/conf_init 1000`
* `vivify`: `/inprocessing/on 1 /inprocessing/conflicts_before_next 5000 /inprocessing/vivify/on 1`
* `all`: `target` and `vivify` together (everything, which needs no advice)
* `all+hints`: `hints`, `target` and `vivify` together
* `tuned:planner`: `/mode/value 1 /decision/vsids/init_order 0 /decision/vsids/init_order_ai 0 /decision/polarity/init_strategy 0 /backtracking/chrono_bt_if_higher_init 50 /backtracking/chrono_bt_if_higher_n 50 /backtracking/chrono_bt_if_higher_s 50 /deletion/clause/frac_to_delete 0.5`
* `tuned:regression`: `/decision/vsids/init_order 1 /decision/vsids/init_order_ai 1 /phase/force_solution 1`
* `flip1000`: the control, a perturbation without information (`/decision/polarity/flip_factor 1000`, a parameter of the C++ solver): what a change of no merit does to the counters

The columns: *same verdicts*: the instances, whose every query gets the verdict of the baseline (a difference, which is not a contradiction, is a query cut off by its conflict budget or by the timeout under one of the two); *decided*: the instances, whose last query is answered; the ratios are geometric means of (x + 1) / (baseline + 1) for the counters and (x + 0.001) / (baseline + 0.001) for the time over the instances both decide with the same answer; *wins/losses*: the instances with fewer/more conflicts than the baseline.
